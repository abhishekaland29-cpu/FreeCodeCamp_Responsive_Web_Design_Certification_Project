Introduction

Cascading Style Sheets (CSS) is a stylesheet language used for describing the presentation of a document written in HTML.

Modern CSS allows for complex layouts without the need for heavy JavaScript interference.

body { background-color: #fff; }
Flexbox Layout

Flexbox is a one-dimensional layout method for arranging items in rows or columns.

Items flex to fill additional space and shrink to fit into smaller spaces.

.container { display: flex; justify-content: center; }
  • Flex-direction
  • Justify-content
  • Align-items
CSS Grid

CSS Grid Layout is a two-dimensional layout system for the web.

It allows you to align content into columns and rows simultaneously.

.grid { display: grid; grid-template-columns: 1fr 1fr; }
Variables and Root

CSS variables (Custom Properties) allow you to store values for reuse throughout a document.

They are defined using the -- prefix and accessed via the var() function.

:root { --main-color: #3498db; }
  • Reusability
  • Dynamic updates
Responsive Design

Responsive web design makes your web page look good on all devices (desktops, tablets, and phones).

Media queries are a key part of responsive design, allowing for different styles based on screen size.

@media (max-width: 600px) { .sidebar { display: none; } }
